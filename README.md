## Project Overview

This project is a Selenium Pytest automation framework created to automate and validate different functionalities of the DemoQA website.

The framework follows the Page Object Model design pattern, where:

- Page classes contain locators and reusable actions.
- Test classes contain test execution flow.
- Configuration files manage browser and application settings.
- Pytest fixtures handle browser setup and teardown.
- Screenshots and logs help in debugging test execution.

## Key Automation Coverage

- Web element interactions
- Form field validation
- Checkbox handling
- Button actions
- Date and time picker automation
- File upload and download
- Explicit waits
- Browser configuration
- Screenshot capture
- Pytest markers
- HTML test reports
